<div class="bili-daily-item">
<h3><span class="bili-daily-index">01</span>阶跃星辰全量开放 Step 5 Preview：600B MoE、27B 激活、1M 上下文</h3>
<p>阶跃星辰正式开放新一代旗舰基座模型 Step 5 Preview，采用稀疏 MoE 架构，总参数量 <span class="bili-daily-metric">600B</span>、每 Token 激活约 <span class="bili-daily-metric">27B</span>，支持 <span class="bili-daily-metric">1M</span> 上下文和视觉输入，定位真实 Agentic 工作，包括代码、金融分析与长程任务。模型目前可通过官方产品和 API 使用，官方计划于 10 月 15 日开放权重。</p>
<p class="bili-daily-meta">发布时间：2026年9月20日</p>
<p class="bili-daily-source">来源：<a href="https://www.stepfun.com/step-5-preview">阶跃星辰官方</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>27B 激活参数意味着它试图用更低的单步计算量承载600B级模型容量；1M上下文和视觉输入则直接面向大型代码库、长文档和多阶段Agent工作流。权重开放后，企业可进一步评估私有部署与推理成本。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">02</span>DeepSeek 明确峰谷计费边界：调休周末与法定节假日全天按闲时价</h3>
<p>DeepSeek开放平台对峰谷计费规则作出进一步说明：调休安排中的上班周末，以及中国法定节假日，全天按空闲时段计费。DeepSeek当前峰谷机制中，空闲时段价格为高峰时段的 <span class="bili-daily-metric">50%</span>；V4.1 Flash仍维持这一机制。</p>
<p class="bili-daily-meta">规则说明发布时间：2026年9月19日</p>
<p class="bili-daily-source">来源：<a href="https://finance.jrj.com.cn/2026/09/19200358493268.shtml">金融界</a>；<a href="https://api-docs.deepseek.com/zh-cn/news/news260910/">DeepSeek 官方定价说明</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>对批处理、评测、数据生成和非实时Agent任务，调度到闲时可以直接把模型调用成本降到高峰时段的一半；新规则也减少了节假日和调休日成本预估的不确定性。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">03</span>B站上线“AI 无限竞技场”，把模型评测扩展到真实工作流</h3>
<p>B站上线“AI 无限竞技场”大模型测评榜，聚合不同领域UP主对上百款模型的同题实测，覆盖代码、推理、协作、知识等场景。首轮榜单并非按单一学术分数排序，而是统计模型在不同测评中获得榜首的次数，并持续开放新的测评者和题目。</p>
<p class="bili-daily-meta">发布时间：2026年9月20日</p>
<p class="bili-daily-source">来源：<a href="https://finance.sina.com.cn/tech/roll/2026-09-20/doc-inismzux1618361.shtml">新浪科技</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>这类榜单不能替代可复现基准，但能补充标准化评测难以覆盖的真实工作流差异。对开发者而言，模型选型可以同时参考基准成绩、Agent框架表现和用户实际任务结果。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">04</span>腾讯开源 WeVisDoc：2B / 4B 文档解析模型直接输出 Markdown</h3>
<p>腾讯开源端到端文档解析模型 WeVisDoc，提供 2B 与 4B 两个版本，可把页面图像直接转换为结构化 Markdown，并保留 LaTeX 公式和 HTML 表格。官方仓库显示，WeVisDoc-4B 在 OmniDocBench v1.6 的 Overall 得分为 <span class="bili-daily-metric">95.38</span>，同时提供 vLLM 本地服务脚本。</p>
<p class="bili-daily-meta">公开时间：2026年9月20日</p>
<p class="bili-daily-source">来源：<a href="https://github.com/Tencent/WeVisDoc">腾讯 WeVisDoc GitHub</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>文档解析是RAG、金融报表、论文处理和企业知识库的前置环节。小参数模型可本地部署，意味着敏感PDF和扫描件可以在企业内网完成结构化，而不必上传第三方OCR服务。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">05</span>Claude Code 连续更新：Auto Mode 改用服务端分类器，并加入 AGENTS.md 回退支持</h3>
<p>Claude Code v2.1.278 将 API、Enterprise 以及部分云平台环境的 Auto Mode 默认切换到服务端分类器，官方说明大多数场景不再收取分类器额外开销，并在 <code>/status</code> 中显示运行方式。前一版 v2.1.277 还加入 AGENTS.md 支持：项目没有 CLAUDE.md 时，可自动读取 AGENTS.md 作为项目指令。</p>
<p class="bili-daily-meta">发布时间：v2.1.278 为2026年9月19日；v2.1.277 为9月18日</p>
<p class="bili-daily-source">来源：<a href="https://github.com/anthropics/claude-code/releases">Anthropic Claude Code Releases</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>AGENTS.md兼容减少了不同Coding Agent之间重复维护项目说明文件的成本；服务端Auto Mode分类则直接影响企业用户的请求路由、计费和可观测性。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">06</span>AWS 发布 AgentCore Runtime V2：2GB 镜像冷启动仍约 2 秒</h3>
<p>AWS推出新一代 Amazon Bedrock AgentCore Runtime。V2采用按需扩张并回收内存的机制，费用按实际内存使用而非会话峰值计算；同时通过环境快照降低冷启动。AWS测试中，200MB到2GB容器镜像的P75冷启动均约 <span class="bili-daily-metric">1.9—2.0秒</span>，旧版为5.4—30秒。</p>
<p class="bili-daily-meta">发布时间：2026年9月18日</p>
<p class="bili-daily-source">来源：<a href="https://aws.amazon.com/about-aws/whats-new/2026/09/new-agentcore-runtime-generally-available/">AWS</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>Agent运行环境常需要浏览器、代码工具和大量依赖，镜像容易膨胀。冷启动不再随镜像体积明显增长，并能回收闲置内存，会直接改善交互式Agent延迟与运行成本。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">07</span>Qwen3.8-LiveTranslate 发布：实时同传平均延迟降至 2.3 秒</h3>
<p>千问发布 Qwen3.8-LiveTranslate，采用 Interleave 架构处理实时同传，官方给出的平均延迟指标 LAAL 从2.8秒降至 <span class="bili-daily-metric">2.3秒</span>。阿里云文档显示其实时API支持60种语言，并支持说话人区分、音频与图像输入以及文本和语音输出。</p>
<p class="bili-daily-meta">发布时间：2026年9月18日</p>
<p class="bili-daily-source">来源：<a href="https://qwen.ai/research/qwen3.8-livetranslate">Qwen 官方</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>同传应用对延迟、说话人识别和上下文连续性同时敏感。模型把这些能力放在一个实时接口中，可减少会议翻译、跨语种客服和直播字幕系统的拼接复杂度。</p>
</div>

<div class="bili-daily-item">

<p class="bili-daily-meta">发布时间：2026年9月18日</p>
