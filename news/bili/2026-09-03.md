## 今日焦点

<section class="bili-daily-item">
<div class="bili-daily-heading"><span class="bili-daily-index">1</span><h3 class="bili-daily-news-title">Anthropic 发布 Claude Fable 5.1：面向编程与长时任务全面开放</h3></div>
<p>Anthropic 于 9 月 1 日发布 Claude Fable 5.1，面向 Pro、Max、Team、Enterprise 用户开放，并通过 Claude Platform、AWS、Google Cloud 与 Microsoft Foundry 提供。API 定价为每百万输入 Token <span class="bili-daily-metric">10 美元</span>、输出 <span class="bili-daily-metric">50 美元</span>；缓存读取降至每百万 Token 0.25 美元，较 Fable 5 下降 75%。Anthropic 估算典型工作负载成本可下降约 25%，高 Agent 化工作负载最高约 45%。</p>
<p class="bili-daily-meta">发布时间：2026-09-01</p>
<p class="bili-daily-source">来源：<a href="https://www.anthropic.com/claude/fable">Anthropic</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>对使用 Claude Code、长时 Agent 与大规模缓存提示词的团队而言，缓存价格变化直接降低持续运行成本；同时 Fable 5.1 已是一般用户可直接使用的最高能力档。</div>
</section>

<section class="bili-daily-item">
<div class="bili-daily-heading"><span class="bili-daily-index">2</span><h3 class="bili-daily-news-title">Claude Mythos 5.1 同步发布，但继续限制在可信机构</h3></div>
<p>Claude Mythos 5.1 与 Fable 5.1 使用同一底层模型，但针对网络安全与生物研究保留更少限制，仅向经过审核的网络防御机构和生命科学研究组织开放。其起步价格同样为每百万输入 Token 10 美元、输出 50 美元。</p>
<p class="bili-daily-meta">发布时间：2026-09-01</p>
<p class="bili-daily-source">来源：<a href="https://www.anthropic.com/claude/mythos">Anthropic</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>Anthropic 正式把“同一底座、不同安全能力开放级别”产品化。普通开发者获得 Fable，而高风险网络安全、生物能力继续通过可信访问计划隔离。</div>
</section>

<section class="bili-daily-item">
<div class="bili-daily-heading"><span class="bili-daily-index">3</span><h3 class="bili-daily-news-title">OpenAI 披露 Astra：首个触及其“Critical”网络安全门槛的模型</h3></div>
<p>OpenAI 公布 Astra 的网络安全评估。Astra 在 ExploitBench 上取得 <span class="bili-daily-metric">100%</span>，并在内部测试中发现并利用两个零日漏洞；专家测试还显示，它能够构造浏览器沙箱逃逸链及从普通用户到 root 的本地提权链。OpenAI 因此确认 Astra 达到其网络安全“critical threshold”，正式开放前将配置更严格的访问与监控机制。</p>
<p class="bili-daily-meta">发布时间：2026-09-01</p>
<p class="bili-daily-source">来源：<a href="https://openai.com/index/path-to-astra/">OpenAI</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>这不是单纯的模型性能升级，而是能力首次触发 OpenAI 最高等级安全发布要求。安全研究者能获得更强工具，但普通用户不会立即获得完整攻击能力。</div>
</section>

<section class="bili-daily-item">
<div class="bili-daily-heading"><span class="bili-daily-index">4</span><h3 class="bili-daily-news-title">Google 为 Gemini 上线 Agentic Video：按需观看视频片段</h3></div>
<p>Google DeepMind 为 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 推出 Agentic Video Understanding。模型不再固定处理整段视频，而是自主决定扫描哪些片段。Google 称该机制最高可减少 <span class="bili-daily-metric">88% Token</span>、降低 <span class="bili-daily-metric">66% 成本</span>，并提升最多 7% 的质量表现。开发者可在 Google AI Studio 和相关 Agent 平台中启用。</p>
<p class="bili-daily-meta">发布时间：2026-09-01</p>
<p class="bili-daily-source">来源：<a href="https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-agentic-video-in-gemini/">Google</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>视频理解的主要成本来自长上下文。若无需完整逐帧读取，视频搜索、审片、监控分析和多媒体 Agent 的 API 成本会直接下降。</div>
</section>
