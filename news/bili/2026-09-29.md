  <p>scriptc 将 TypeScript / JavaScript 编译为 typed IR、C、LLVM IR、原生对象、可执行文件或 WebAssembly。静态构建产物不依赖 Node 或 JavaScript 引擎；动态代码则可显式启用 quickjs-ng。</p>
  <p class="bili-daily-meta">发布时间：2026-09-27 ｜ 来源：<a href="https://github.com/vercel-labs/scriptc/releases">GitHub Releases</a></p>
  <p class="bili-daily-why"><strong>为什么值得关注：</strong>这为 CLI、边缘工具和单文件分发提供了不同于传统 Node 打包器的新路径：代码仍写 TypeScript，但最终可以得到原生二进制或 WASM。</p>
