<h3><span class="bili-daily-index">01</span>Anthropic 发布 Claude Opus 5.5：更快、更便宜，并引入更严格安全措施</h3>
<span class="bili-daily-meta">真实发布时间：2026-09-22</span>
<p>Anthropic 发布 Claude Opus 5.5，官方称其在多数工作任务上可达到 Claude Fable 5.1 水平。相比 Opus 5，典型工作负载运行成本约下降 <span class="bili-daily-metric">40%</span>，输出速度提高超过 <span class="bili-daily-metric">30%</span>。API 定价为每百万输入 Token 4 美元、输出 Token 20 美元，缓存读取为 0.20 美元。</p>

<section class="bili-daily-item">
<h3><span class="bili-daily-index">03</span>DeepSeek 公开 DSec：大规模 Agent 训练开始把“沙盒基础设施”单独做成系统</h3>
<span class="bili-daily-meta">论文公开：2026-09-19；相关技术细节于 2026-09-23 集中传播</span>
<p>DeepSeek 团队公开论文《DeepSeek Elastic Compute (DSec): A Sandbox Infrastructure for Effective Agentic Training at Scale》。DSec 将函数调用、容器、microVM 和完整虚拟机统一到一套 SDK 下，并针对 Agent 训练中大量、短生命周期、状态化执行环境进行调度。</p>
<p>公开数据称，一套生产单元约包含 160 个 CPU 节点、3 万个核心和 250TB 内存，每天服务约 <span class="bili-daily-metric">300 万</span> 个沙盒，峰值并发超过 <span class="bili-daily-metric">38 万</span>，每秒可创建超过 <span class="bili-daily-metric">5000</span> 个沙盒。</p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>大规模 Agent 强化学习的瓶颈不只在 GPU 和模型，可靠、隔离、可快速恢复的执行环境同样决定训练吞吐。DSec 把这一层从“脚本和容器编排”提升为专门基础设施。</p>
<p class="bili-daily-source">来源：<a href="https://arxiv.org/abs/2609.22978">论文页面</a> ｜ <a href="https://www.emergentmind.com/papers/2609.22978">论文摘要镜像</a></p>
</section>

<h3><span class="bili-daily-index">12</span>OpenAI 公布第三方安全评估原则，强调从训练到部署的深度访问</h3>
<span class="bili-daily-meta">真实发布时间：2026-09-22</span>
