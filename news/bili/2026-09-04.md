<div class="bili-daily-heading"><span class="bili-daily-index">01</span><span>OpenAI 发布 GPT-6 Astra，企业可信访问先行开放</span></div>
GPT-6 Astra 于9月3日正式发布。OpenAI将其定位为当前旗舰模型，API文档给出的上下文窗口为 <span class="bili-daily-metric">1,050,000 tokens</span>、最大输出 <span class="bili-daily-metric">128,000 tokens</span>，API价格为每百万输入token <span class="bili-daily-metric">10美元</span>、输出token <span class="bili-daily-metric">50美元</span>。首批通过 Trusted Access Program 向企业开放，更广泛的API与ChatGPT套餐接入将随后推进。OpenAI同时披露，Astra达到其Preparedness Framework中的“Critical”网络安全能力阈值，因此高阶网络能力采用更严格的访问和防护措施。
<div class="bili-daily-meta">发布时间：2026-09-03</div>
<div class="bili-daily-source">来源：<a href="https://developers.openai.com/api/docs/models/gpt-6-astra">OpenAI API Docs</a> · <a href="https://openai.com/index/path-to-astra/">OpenAI｜The path to Astra</a></div>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>Astra直接改变高端模型的能力、上下文和API成本基线；同时，“Critical”网络能力意味着部分安全能力不会按普通API权限完全开放，企业接入时需要额外考虑权限与合规流程。</div>
