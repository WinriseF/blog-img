<div class="bili-daily-head"><span class="bili-daily-index">1</span><h3>Codex 停用 GPT-5.4 / GPT-5.4 mini，ChatGPT 登录用户转向 GPT-5.6 Terra 与 Luna</h3></div>
<div class="bili-daily-meta">发布时间：2026-08-31｜来源：OpenAI Help Center</div>
OpenAI 明确说明，自 8 月 31 日起，通过 ChatGPT 账户登录 Codex 时，GPT-5.4 与 GPT-5.4 mini 不再可用；官方建议分别迁移到 <span class="bili-daily-metric">GPT-5.6 Terra</span> 和 <span class="bili-daily-metric">GPT-5.6 Luna</span>。该变化不影响 OpenAI API，也不影响使用自有 API Key 的 Codex。

来源：https://help.openai.com/en/articles/11369540
<div class="bili-daily-why"><strong>为什么值得关注：</strong>这会直接影响 Codex 的 workspace 默认模型、保存的模型设置、托管配置和自动化；依赖旧模型名称的工作流需要更新。</div>
</section>

</section>
