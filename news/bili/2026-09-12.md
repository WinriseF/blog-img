## AI 与开发工具

<div class="bili-daily-item">
<h3><span class="bili-daily-index">01</span>DeepSeek 发布 V4.1 Flash：552B MoE，原生多模态，KV Cache 大幅压缩</h3>
<p>DeepSeek 于9月10日发布 V4.1 Flash。模型总参数 <span class="bili-daily-metric">552B</span>，采用 Causal Encoder-Decoder 非对称结构，输入激活 8B、输出激活 16B。官方称其基准能力超过 DeepSeek V4 Pro，KV Cache 的 HBM 占用降至上一代的四分之一、SSD 占用降至八分之一；API 已上线并支持原生多模态。</p>
<p class="bili-daily-meta">发布时间：2026年9月10日</p>
<p class="bili-daily-source">来源：<a href="https://www.deepseek.com/en/news/deepseek-v4-1-flash/">DeepSeek 官方</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>对长上下文Agent和高并发推理来说，KV Cache 占用直接影响GPU显存、SSD容量和整体部署成本；这次升级同时改变了模型能力与推理经济性。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">02</span>OpenAI Agents API 公测：把 Codex harness 直接开放给开发者</h3>
<p>OpenAI 于9月10日推出 Agents API 公测版。该API由 Codex 的开源 harness 驱动，OpenAI 负责托管模型调用、上下文管理、工具协调与长时间运行任务；开发者可选择 OpenAI 托管沙箱、自有基础设施或第三方沙箱。公测阶段 <span class="bili-daily-metric">不额外收取API平台费</span>，按实际使用的模型Token和工具计费。</p>
<p class="bili-daily-meta">发布时间：2026年9月10日</p>
<p class="bili-daily-source">来源：<a href="https://openai.com/index/introducing-the-agents-api/">OpenAI</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>开发者不再需要自行搭建完整Agent Loop、上下文管理和子Agent编排基础设施，可以把更多工程投入放在业务工具、权限和任务设计上。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">03</span>GPT-Live-1 进入API：支持全双工语音、打断与后端Agent委托</h3>
<p>OpenAI 将 GPT-Live-1 开放给API开发者。模型可以同时听和说，处理自然打断、停顿与简短回应，并可把复杂推理和工具操作委托给后端模型或Agent。API支持浏览器WebRTC、服务器WebSocket及电话场景。</p>
<p class="bili-daily-meta">发布时间：2026年9月10日</p>
<p class="bili-daily-source">来源：<a href="https://openai.com/index/introducing-gpt-live-1-in-the-api/">OpenAI</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>传统语音Agent往往需要ASR、LLM、TTS三段式拼接；全双工模型能减少架构复杂度和对话延迟，更适合客服、助手和实时操作场景。</p>
</div>
