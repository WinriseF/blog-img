## AI 与开发工具

<div class="bili-daily-item">
<h3><span class="bili-daily-index">06</span>Cohere 发布 Parse 5：2.3B 多模态文档解析模型，可直接输出结构化 Markdown</h3>
Cohere Parse（模型 ID：parse-v5.0）是一款 <span class="bili-daily-metric">2.3B</span> 参数的多模态文档解析模型，可处理表格、列表、表单、图片、标题和页面边界，并返回 Markdown / HTML、边界框与图像描述。官方给出的模型大小约 4.6GB、上下文 8K，并通过 Parse API、Microsoft Foundry、AWS SageMaker 和 Model Vault 提供。
<div class="bili-daily-meta">发布时间：2026-08-27</div>
来源：https://cohere.com/blog/parse ｜ https://docs.cohere.com/v1/changelog/parse
<div class="bili-daily-why"><strong>为什么值得关注：</strong>复杂 PDF 和扫描文档进入 RAG 前通常要经过 OCR、版面恢复和表格抽取；Parse 把这些步骤合并成单一模型接口，可减少文档 AI 管线中的中间组件。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">07</span>Google DeepMind 试点全球首个前沿模型“双盲评测”</h3>
Google DeepMind 推出针对闭源前沿模型的双盲评测机制：外部评测题保存在加密环境中，模型提供方看不到测试题，评测方也接触不到模型权重，以降低 benchmark contamination 和针对评测集优化的风险。
<div class="bili-daily-meta">发布时间：2026-08-27</div>
来源：https://deepmind.google/blog/piloting-the-worlds-first-double-blind-ai-evaluations/
<div class="bili-daily-why"><strong>为什么值得关注：</strong>模型榜单越来越容易受到训练数据泄漏和针对性优化影响；双盲机制如果被更多机构采用，会提高闭源模型横向比较的可信度。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">08</span>英国 AI Security Institute 开源 optstop，LLM 评测可少跑 57%—97% 的计划试验</h3>
AISI 发布开源 Python 工具 optstop，用贝叶斯方法持续判断评测结果是否已经足够精确或稳定，并在满足条件时提前停止重复试验。其在 MATH、GPQA Diamond、WritingBench 等测试中减少了 <span class="bili-daily-metric">57%—97%</span> 的计划运行次数，同时保持评分结论一致。
<div class="bili-daily-meta">发布时间：2026-08-27</div>
来源：https://www.aisi.gov.uk/blog/optimal-stopping-spending-evaluation-compute-where-it-counts ｜ https://github.com/UKGovernmentBEIS/optstop
<div class="bili-daily-why"><strong>为什么值得关注：</strong>当一次 Agent 评测需要数千万甚至上亿 Token 时，动态停止比固定重复次数更节省成本；这对模型对比、回归测试和安全评测尤其直接。</div>
</div>
