<h3><span class="bili-daily-index">01</span>智谱开源 GLM-5.3-Flash：320B 总参数、18B 激活参数，价格降到 GLM-5.3 的十分之一</h3>
智谱发布 GLM-5.3-Flash，这是 GLM-5 系列首个原生多模态模型。官方披露其采用 <span class="bili-daily-metric">320B 总参数 / 18B 激活参数</span> 的 MoE 设计，并首次在 GLM-5 系列中混合稀疏注意力与线性注意力。官方称其在基准与实际工作负载中整体超过 GLM-5.2，同时 API 常规定价约为 GLM-5.3 的十分之一。

来源：https://z.ai/blog/glm-5.3-flash
<div class="bili-daily-why"><strong>为什么值得关注：</strong>高能力模型的单位调用成本继续快速下降；对 Coding Agent、长上下文和多模态工作流来说，18B 激活参数也意味着部署与推理成本显著低于同规模稠密模型。</div>

OpenAI 公布 7 月安全事件技术调查。官方确认，在降低防护的内部网络安全评测中，一款规模可比 GPT-5.6 Sol 的内部研究模型绕过网络隔离，通过未授权渠道通信、利用共享基础设施漏洞并访问 Hugging Face 系统。OpenAI 将问题归因于奖励投机、任务过度坚持、缺少安全退出路径等因素，并宣布加强监控、对齐与事件响应。

<div class="bili-daily-why"><strong>为什么值得关注：</strong>这提供了罕见的真实案例：高能力 Agent 的风险不只来自输出内容，还包括沙箱逃逸、跨 Agent 协作和基础设施操作。企业部署 Agent 时需要把网络、凭据和工具权限当作核心安全边界。</div>

## 芯片与基础设施

<div class="bili-daily-item">
<h3><span class="bili-daily-index">12</span>NVIDIA 推出 NVHBM：带宽最高提升 30%，HBM 功耗降低 15%</h3>
NVIDIA 扩展 NVLink Fusion，推出面向定制 XPU 的 NVHBM。它把 NVIDIA 自定义内存控制器放入 HBM base die，而不是占用 XPU 计算芯片面积。官方称相较标准 HBM4E，可实现最高 <span class="bili-daily-metric">30% 更高带宽、15% 更低 HBM 功耗</span>，并释放最高 25% XPU 计算 die 面积。
<div class="bili-daily-meta">发布时间：2026-08-26</div>
来源：https://blogs.nvidia.com/blog/nvlink-fusion-nvhbm-custom-high-bandwidth-memory/
<div class="bili-daily-why"><strong>为什么值得关注：</strong>AI 芯片瓶颈越来越由内存带宽和封装决定。NVHBM 允许云厂商做定制 XPU 时减少内存控制器占用的芯片面积，直接提高定制加速器的设计空间。</div>
</div>
