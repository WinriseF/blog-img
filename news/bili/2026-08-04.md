8 月初的模型发布潮里，最值得注意的变化并不是参数规模再次膨胀，而是任务的时间尺度被突然拉长。

阿里发布的 [Qwen3.8-Max](https://qwen.ai/blog?id=qwen3.8) 拥有 2.4 万亿总参数，每次推理激活 950 亿参数，可处理文本、图像与视频，并支持最高 100 万 token 的上下文。比这些规格更具指向性的，是一个看似朴素的数字：它完成了一项持续 16 天的软件工程项目。与此同时，[OpenAI 的 GPT-5.6](https://openai.com/index/gpt-5-6/) 开始把“连续数日保持任务状态”、程序化调用工具以及多个智能体并行协作写进核心能力；DeepSeek V4-Flash 则用极低价格证明，长时间运行的前提不只是模型足够聪明，还要足够便宜。

这意味着 AI 编程正在离开“问一句、答一段、改一次”的聊天节奏。下一阶段的竞争对象不再只是某个代码补全窗口，而是一套可以在云端持续运行、反复测试、保存状态、控制预算并交付结果的生产系统。

## 十六天，把模型能力换成项目周期

过去两年的编程模型主要在缩短局部操作：生成一个函数、解释一段报错、补齐一组测试。它们的价值容易用几分钟内的结果衡量，也容易通过人工不断纠偏。但一个持续 16 天的工程任务，考验的是另一组能力。

模型需要记住此前做过什么，理解代码库在多轮修改后的新状态，发现测试失败后回溯原因，并在依赖、权限、环境和需求发生变化时调整计划。任何一次错误都可能在后续步骤中被放大；任何一次状态丢失，都可能让数天工作重新开始。此时，代码生成能力只是底座，真正决定能否交付的是任务分解、工具使用、记忆管理、失败恢复和验收机制。

Qwen3.8-Max 采用混合专家架构，总参数达到 2.4 万亿，但每次仅激活 950 亿参数，以降低推理开销和延迟。它计划开放模型权重，使企业能够在自有环境中部署、微调或建立专用智能体。[路透社对这次发布的报道](https://www.reuters.com/business/retail-consumer/alibaba-unveils-its-most-capable-ai-model-date-not-far-behind-moonshots-size-2026-08-03/)指出，这种路线瞄准的并不只是最高分，而是“足够强、可负担、透明且可获得”的企业工作流。

开放权重在长任务场景中的意义尤其突出。短对话可以容忍一次外部 API 波动，持续数日的工程流程却更在意版本稳定、数据边界、部署位置和恢复能力。模型一旦成为生产链的一部分，能否控制运行环境，往往与模型本身的能力同样重要。

## 旗舰模型开始争夺持续工作

OpenAI 对 GPT-5.6 的描述同样把重点从单轮回答移向完整工作流。它可以编写并运行轻量程序，协调工具、筛选中间结果、监控进度并决定下一步动作；`max` 模式允许模型投入更多时间探索和检查，`ultra` 则默认让四个智能体并行处理不同工作流，在复杂任务上用更多 token 换取更短的交付时间。

这种设计改变了“更快”的含义。过去的速度主要是每秒输出多少 token，现在更重要的是从任务开始到可用成果之间经过多久。一个模型即使单次响应稍慢，只要能够减少返工、压缩工具往返次数并稳定完成多阶段任务，整体效率仍可能更高。反过来，一个回答很快但频繁偏离目标的模型，在数日流程里会积累出更高成本。

长任务的边界也已经超出软件开发。8 月 1 日，OpenAI 公布了内部模型 Astra 在数学和理论计算机科学中的 [十项研究进展](https://openai.com/index/ten-advances-in-mathematics/)，涉及高维球堆积、编码理论、群论、量子复杂性和格密码等问题。OpenAI 称，寻找这些解法所消耗的 token，按 GPT-5.6 Sol API 价格估算约为 2000 美元，并为每项结果提供了论文与 Lean 形式化证书。这些成果仍需要专业共同体持续审阅，但它们展示了一种新的使用方式：模型可以围绕开放问题展开长时间搜索，生成可检查的中间产物，再由人类研究者整理和判断。

从代码库到数学问题，共同点不是“无人参与”，而是人机分工发生变化。人类更集中于定义目标、设定边界、选择证据和判断结果，模型则承担大量可并行、可重复、需要耐心的搜索与执行。

## 价格战正在改写部署逻辑

任务从几分钟延长到几天后，价格不再是账单末尾的小数，而会直接决定产品是否成立。

[DeepSeek V4-Flash](https://www.reuters.com/business/retail-consumer/deepseeks-new-ai-model-is-by-far-cheapest-well-known-models-run-research-firm-2026-08-03/)的输入价格为每百万 token 0.14 美元，输出价格为 0.28 美元。Artificial Analysis 按完成综合测试所需的实际 token 估算，其平均成本约为 0.03 美元；同一口径下，Kimi K3 约为 0.86 美元，GPT-5.6 Sol 为 1.86 美元，Claude Fable 5 为 3.15 美元。V4-Flash 的综合能力仍落后于最强封闭模型，但百倍级成本差足以改变系统架构。

企业不必再把所有步骤交给同一个旗舰模型。代码格式化、日志归类、候选方案扩展、重复测试和资料预处理，可以由低成本模型持续执行；架构决策、复杂调试、安全审查和最终验收，再切换到更强模型。模型路由因此从节省预算的附加功能，变成长期智能体的基础设施。

这也解释了为什么“每百万 token 单价”越来越不足以衡量价值。真正有意义的指标，是完成一个合格任务需要多少轮调用、多少次重试、多少人工介入，以及失败后能否从检查点恢复。便宜模型如果需要大量返工，最终成本未必低；昂贵模型若能一次穿过关键决策点，也可能更经济。未来的采购比较将从模型价目表转向“每项可验收成果的总成本”。

## 真正的瓶颈开始下沉到云与电

当大量智能体全天候运行，模型公司的竞争也会沿着技术栈向下移动。持久化文件系统、隔离执行环境、状态存储、网络访问、日志追踪和权限控制，都会成为体验的一部分。再往下，则是芯片、机房与电力。

Anthropic 在 4 月宣布与亚马逊扩展合作，为 Claude 获取 [最高 5 吉瓦的新算力容量](https://www.anthropic.com/news/anthropic-amazon-compute)，并计划在十年内向 AWS 技术投入超过 1000 亿美元。公司称其已经使用超过 100 万颗 Trainium2 芯片，预计 2026 年底前上线接近 1 吉瓦的 Trainium2 与 Trainium3 容量。随后公布的 [Google 与 Broadcom 合作](https://www.anthropic.com/news/google-broadcom-partnership-compute)又锁定了从 2027 年开始上线的数吉瓦 TPU 容量。

这些数字远远超过传统软件公司的基础设施尺度。7 月披露的一项长期租约更具体地展示了算力如何变成能源资产：Anthropic 将使用肯塔基州一座约 401 兆瓦的 AI 园区，初始租期 20 年，合同收入预计约 190 亿美元。[提交给美国证券交易委员会的材料](https://www.sec.gov/Archives/edgar/data/1083301/000110465926080583/tm2619468d1_ex99-1.htm)显示，该园区计划从 2027 年下半年开始投入容量，并在 2028 年初达到满负荷。

模型可以持续工作多久，最终取决于服务是否稳定、计算资源是否充足以及每轮执行是否负担得起。长任务越普及，峰值时段的排队、区域容量、故障恢复和电价就越可能传导到产品层。所谓“智能体体验”，背后其实是一条从模型权重延伸到电网的供应链。

## 开发者要重新设计软件生产线

长任务模型不会简单地把现有开发流程自动化，而会迫使团队重新定义流程本身。

第一，任务必须可分解、可暂停、可恢复。数日运行不能依赖一段不断增长的聊天记录，而应有明确的计划、阶段产物、检查点和失败策略。第二，权限必须按步骤授予。能够访问代码仓库、数据库、云控制台和发布系统的智能体，持续运行时间越长，潜在影响范围越大；最小权限、隔离环境和可追溯操作会成为默认要求。第三，验收标准必须先于执行建立。没有测试、性能预算和业务约束，模型只会更高效地走向一个模糊终点。

对个人开发者而言，工作方式也会从“盯着模型写代码”转向“安排任务并检查交付”。真正稀缺的能力不再只是写出某段实现，而是把需求转化为可以被机器持续执行的任务，识别哪些决策必须由人承担，并建立足够可靠的反馈环。对企业而言，竞争优势则可能来自模型之外：更好的内部工具接口、更干净的数据、更稳定的测试体系，以及能在多种模型之间切换的运行平台。

AI 编程正在成为一种云端生产能力，而不再只是编辑器里的功能。Qwen3.8-Max 的十六天案例、GPT-5.6 的并行智能体、DeepSeek 的低成本推理，以及模型公司对吉瓦级算力的争夺，指向同一个结果：下一轮竞争衡量的将不是谁能写出最惊艳的一段代码，而是谁能以可控成本，把一项复杂工作持续推进到可以交付。
