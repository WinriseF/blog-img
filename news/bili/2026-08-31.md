## 今日焦点

<div class="bili-daily-item">
<h3><span class="bili-daily-index">1</span>OpenAI 将终止向 Cursor 直接提供模型，拟于 11 月 12 日关闭</h3>
<div class="bili-daily-meta">发布时间：2026-08-28（OpenAI 官方）；Reuters 于 2026-08-29 跟进报道</div>
<p>OpenAI 表示，SpaceX 收购 Cursor 后触发双方合同中的控制权变更条款，公司计划结束面向 Cursor 的模型供应，拟定停止日期为 <span class="bili-daily-metric">2026年11月12日</span>。OpenAI 同时称未来模型不会继续通过该商业合作提供给 Cursor。</p>
<p>来源：<a href="https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/">OpenAI 官方公告</a>；<a href="https://www.reuters.com/business/media-telecom/openai-end-partnership-with-spacexs-cursor-2026-08-29/">Reuters</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>这直接影响依赖 Cursor 内置 OpenAI 模型的开发者工作流。停止的是 Cursor 与 OpenAI 的商业供应关系，而不是所有通过 OpenAI 自有接口使用模型的方式，团队需要在 11 月前确认模型路由和替代方案。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">2</span>Codex 今日停止提供 GPT-5.4 与 GPT-5.4 mini（ChatGPT 登录方式）</h3>
<div class="bili-daily-meta">生效日期：2026-08-31（OpenAI Help Center）</div>
<p>OpenAI 帮助中心明确：从今天起，使用 ChatGPT 账户登录 Codex 时，GPT-5.4 与 GPT-5.4 mini 不再可用，官方建议分别迁移到 <span class="bili-daily-metric">GPT-5.6 Terra</span> 与 <span class="bili-daily-metric">GPT-5.6 Luna</span>。API 和自带 API Key 的 Codex 使用方式不受此项变更影响。</p>
<p>来源：<a href="https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan">OpenAI Help Center</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>工作区默认模型、自动化脚本和保存的模型配置如果仍引用旧模型，今天起可能直接失效，需要立即更新。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">3</span>美国联邦法官阻止五角大楼将 Anthropic 列为供应链风险</h3>
<div class="bili-daily-meta">发布时间：2026-08-28</div>
<p>美国联邦法官裁定，五角大楼针对 Anthropic 的相关措施缺乏合法依据，并暂时阻止其以“供应链风险”名义实施限制。争议核心涉及 Anthropic 对大规模监控及自主武器用途的限制立场。</p>
<p>来源：<a href="https://www.reuters.com/legal/government/us-judge-blocks-pentagons-anthropic-blacklisting-2026-08-28/">Reuters</a>；<a href="https://apnews.com/article/f15e3c30186385e73e72bee82d85b05c">AP</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>判决会直接影响政府采购中如何以国家安全理由限制 AI 供应商，也关系到模型厂商是否能在军用场景中保留自身使用边界。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">4</span>Sony Music Publishing 与 Warner Chappell 起诉 Anthropic</h3>
<div class="bili-daily-meta">发布时间：2026-08-29</div>
<p>两家音乐出版商在美国联邦法院起诉 Anthropic，指控其未经授权获取并使用大量受版权保护作品训练 Claude。诉状寻求的法定赔偿最高可达每部作品 <span class="bili-daily-metric">15万美元</span>，并涉及版权管理信息被移除等额外主张。</p>
<p>来源：<a href="https://www.theverge.com/ai-artificial-intelligence/986438/sony-music-warner-chappell-anthropic-lawsuit-copyright">The Verge</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>诉讼重点从“模型输出是否侵权”继续向“训练数据取得方式是否合法”延伸，可能提高大型模型数据采购、授权和数据溯源成本。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">5</span>Nvidia 被曝同意以 129 亿美元收购 Hugging Face</h3>

<p>来源：<a href="https://www.reuters.com/technology/nvidia-talks-acquire-hugging-face-13-billion-deal-business-insider-reports-2026-08-27/">Reuters</a></p>
<div class="bili-daily-why"><strong>为什么值得关注：</strong>如果交易完成，Nvidia 将从 GPU 与系统软件进一步进入开源模型分发和开发者生态层，对模型托管、推理服务和开源社区治理都有直接影响。</div>

<div class="bili-daily-item">
