<p>OpenAI 于 9 月 3 日发布 GPT‑6 Astra。官方称 Astra 在计算机操作、浏览、软件工程、网络安全、科学与专业工作等任务上取得新进展，并将在未来几天逐步向 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，同时进入 OpenAI API、Microsoft Azure 与 AWS Bedrock。标准 API 价格为每百万输入 Token <span class="bili-daily-metric">10 美元</span>、输出 Token <span class="bili-daily-metric">50 美元</span>。</p>

</div>

<p class="bili-daily-why"><strong>为什么值得关注：</strong>说话人分离与词级时间戳是生产级 ASR 的关键能力，直接减少开发者额外拼装第三方音频处理流水线的需求。</p>
</div>

<div class="bili-daily-item">

<p class="bili-daily-meta">发布时间：2026年9月3日</p>
<p class="bili-daily-source">来源：<a href="https://github.com/anthropics/claude-code/issues/91870">GitHub — anthropics/claude-code #91870</a></p>
<p class="bili-daily-why"><strong>为什么值得关注：</strong>如果该方案正式落地，Claude Code 插件将从现有 Shell Hook 扩展到更细粒度的程序化控制，企业可更系统地做权限、审计和工作流定制。</p>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">05</span>IFM 推出 K2 Horizon 系列开放权重模型</h3>

<p class="bili-daily-meta">发布时间：2026年9月3日</p>
<p class="bili-daily-source">来源：<a href="https://github.com/ggml-org/llama.cpp/discussions/28308">llama.cpp Discussion — K2 Horizon</a></p>

</div>

<div class="bili-daily-item">

<p class="bili-daily-meta">发布时间：2026年9月3日</p>

</div>

<h3><span class="bili-daily-index">20</span>Google 发布 WeatherNext 3，并接入 Search、Gemini、Maps 与 Cloud</h3>
<p>Google DeepMind 与 Google Research 推出 WeatherNext 3。新模型使用实时卫星数据，能够逐小时刷新预报，并提供比上一代更高的空间分辨率和更精细的降水预测。Google 已将其接入 Search、Gemini、Maps、Google Maps Platform 与 Cloud。</p>

<p class="bili-daily-why"><strong>为什么值得关注：</strong>天气 AI 从研究模型直接进入消费产品和云 API，意味着农业、物流、能源和地图应用可以更快获得高频率、高分辨率的预测数据。</p>
