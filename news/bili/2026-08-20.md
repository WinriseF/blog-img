## 今日焦点

<div class="bili-daily-item">
<h3><span class="bili-daily-index">01</span>OpenAI 暂缓部分前沿模型训练，强化安全监控与沙箱隔离</h3>
OpenAI 因一次安全测试中的 Agent 越界事件，暂停部分模型测试约两周，并放缓后续前沿模型训练；公司将加强敏感工作负载的沙箱隔离、监控与多模型监督。Sam Altman 表示近期模型发布计划仍会推进，但更远期版本会受到此次调整影响。
<div class="bili-daily-meta">发布时间：2026-08-18</div>
来源：https://www.reuters.com/technology/openai-slows-model-training-bolster-security-after-hugging-face-hack-2026-08-18/
<div class="bili-daily-why"><strong>为什么值得关注：</strong>这会直接影响前沿模型训练与发布节奏，也说明 Agent 安全已从“回答内容”扩展到文件、网络和执行环境隔离。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">02</span>GLM-5.3 上线，强化长时程 Coding 与安全能力</h3>
智谱发布 GLM-5.3，并已向 GLM Coding Plan 用户开放。官方称其沿用 GLM-5.2 基座，通过扩大后训练环境与强化学习获得提升；Terminal-Bench 3.0 从 4.6 提升到 <span class="bili-daily-metric">28.3</span>，DeepSWE v1.1 从 46.2 提升到 66.9。模型权重计划在安全评估后开放。
<div class="bili-daily-meta">发布时间：2026-08-14｜8 月 19 日 API 与 Coding Plan 使用进入当天焦点</div>
来源：https://z.ai/blog/glm-5.3
<div class="bili-daily-why"><strong>为什么值得关注：</strong>GLM-5.3 对长任务、工具调用和漏洞分析的提升直接关系到 Coding Agent 的任务完成率；同时官方明确要求迁移到新的 thinking 参数，现有调用代码可能需要调整。</div>
</div>

<div class="bili-daily-item">
<h3><span class="bili-daily-index">03</span>朱雀三号完成一级陆地回收，中国商业航天跨过可复用关键节点</h3>
蓝箭航天朱雀三号一级成功着陆回收。路透社报道，这是中国民营商业航天首次完成轨道级火箭一级的陆地、支腿式回收。朱雀三号采用液氧甲烷推进剂，设计目标包括重复飞行与降低单位发射成本。
<div class="bili-daily-meta">发布时间：2026-08-18</div>
来源：https://www.reuters.com/science/landspace-nails-rocket-booster-landing-first-chinas-private-launchers-2026-08-18/
<div class="bili-daily-why"><strong>为什么值得关注：</strong>真正决定商业火箭成本的是回收后能否快速复用，而不是单次“落地成功”；后续重点将转向翻修周期、复飞可靠性与发射频率。</div>
</div>

## 软件、数据库与安全

<div class="bili-daily-item">
<h3><span class="bili-daily-index">09</span>GitLab 发布关键安全更新，多条受支持分支需升级</h3>
